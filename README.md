# Welcome to my portfolio site!

If you're reading this, it means you're actually interested in how I built my portfolio site - good on you!

The first version of this portfolio was entirely coded by hand with HTML, CSS, and JavaScript. Today, it's still _mostly_ hand-coded, with a little help from Vite now. It turns out I like building with components!

To run this yourself, if you're that curious, you can clone this repo down and run an `npm i` to install all the necessary packages. Then, run `npm run dev` to spin the app up. Simple as that!
